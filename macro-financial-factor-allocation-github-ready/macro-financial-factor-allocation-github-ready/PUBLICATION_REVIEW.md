# Review before publishing

- [ ] Confirm you are comfortable sharing the model implementation, model parameters, and selected figures.
- [ ] Check `src/`, notebook, and `userguide.md` for sensitive details or personal paths. A basic automated scan is not a confidentiality guarantee.
- [ ] Verify rights to share figures derived from external data, and provide suitable attribution.
- [ ] Decide whether to provide a separately approved public research summary (not included).
- [ ] Do not upload the original Word reports or complete archive by accident.
- [ ] Keep the repository private until all reviews are complete.
- [ ] Test a clean checkout with appropriately licensed data before making any claim of full reproducibility.

**Deliberately excluded:** original raw datasets, source manifests/hashes, complete generated result CSVs, reference results, full Word reports, and documentation evidence snapshots.
