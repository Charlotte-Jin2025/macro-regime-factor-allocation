# Data availability

The source archive contains input data from external providers. **Raw data are intentionally not redistributed in this public edition** pending source-by-source redistribution review.

The scripts currently expect the original directory layout and input hashes. To reproduce the analysis, obtain the licensed/authorized source files and restore the `data/us/`, `data/international/`, and `data/realtime/` structure as applicable, with the original `data/input_manifest.json`. Merely downloading the latest versions may not reproduce archived hashes.

The full private archive remains the reproducibility reference. Do not describe this public subset as independently executable without its inputs.
